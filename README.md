# MOHAK — المحقق

لعبة تحقيق جنائي تفاعلية باللغة العربية، تعمل مباشرة في المتصفح دون تثبيت أو خادم خلفي.

## تشغيل اللعبة
- افتح [اللعبة](https://ziedb1132-cpu.github.io/Mohak/) بعد تفعيل GitHub Pages.
- أو افتح ملف `index.html` محلياً في أي متصفح حديث.

## المزايا
- قضايا خيالية متعددة بمستويات صعوبة متدرجة.
- فحص مسرح الجريمة وجمع الأدلة.
- استجواب المشتبه بهم ومقارنة الأقوال.
- لوحة أدلة لتجميع خيوط التحقيق.
- إصدار اتهام نهائي وتقييم اكتمال التحقيق.
- حفظ القضايا المحلولة محلياً في المتصفح.

## النشر عبر GitHub Pages
من إعدادات المستودع اختر **Settings → Pages**، ثم **Deploy from a branch**، وحدد الفرع `main` والمجلد `/ (root)` ثم احفظ. بعد اكتمال النشر ستعمل اللعبة على رابط GitHub Pages أعلاه.

> جميع القضايا والشخصيات والأحداث خيالية لأغراض الترفيه.
